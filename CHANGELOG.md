# Changelog

## 0.2.0-alpha

- Added Scenario Studio with ordered phases, per-phase frequency, browser storage, JSON import and downloads.
- Added explicit timeouts, configurable HTTP errors and truncated response bodies.
- Added healthy baseline versus fault replay, per-request contract checks, latency percentiles and a stable scenario fingerprint.
- Added `run` and `serve --scenario` to the CLI and preserved the four original `demo` cases.
- Added a strict TypeScript build, locked development tools and CI for compilation and local integration tests.

## 0.1.0

- Initial loopback inventory fixture, demo consumer, delay, HTTP 503, disconnect and JSON contract report.
