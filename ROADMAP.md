# Roadmap

## Alpha feedback

- Compare how developers use an exported scenario in their existing local client tests.
- Evaluate scenario and report schema changes with integration examples before promising compatibility across major versions.
- Expand verified browser and platform coverage after the initial tester group.

## After Alpha

- Consider named fixture presets and versioned schemas for other synthetic HTTP contracts.
- Assess workflows for comparing saved measurements of the same scenario and flagging regressions.
